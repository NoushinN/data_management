Data Management with R

Chapter 27 19. Key Takeaways

In this practice, you learned how to:

  • Clean and separate character columns.
  • Use stringr functions to trim and extract text.
  • Use regular expressions to identify text patterns.
  • Reshape data from wide format to long format.
  • Convert coded column names into meaningful variables.
  • Summarize and visualize categorical data.
